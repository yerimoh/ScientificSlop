# ScientificSlop
Science or Slop?: BENCHMARKING AND MITIGATING SCIENTIFIC SLOP IN AI-GENERATED PAPERS

## SciSlopBench

The benchmark (390 AI/human paper pairs, 773 paper bodies in two views, per-paper SciSlop measures and detector
baselines) is in [`scislopbench/`](scislopbench/): three Parquet tables under `scislopbench/data/` and a
[dataset card](scislopbench/README.md) describing the pairing rule, the schema and how to recompute Table 2.
